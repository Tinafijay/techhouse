Keyboard Shortcuts Quick Guide:

  • Home: Return playhead to start (0)
  • Up / Down Arrows: Navigate focus between tracks
  • Left / Right Arrows: Move playhead by 1 beat
  • Shift + Left / Right: Move playhead by 1 bar
  • Ctrl + Left / Right: Move playhead by 1/16 note
  • Space: Play / Pause playback, or Pause / Resume recording
  • R: Start recording, or Stop recording if already recording
  • S / E: Mark In and Out region selection points
  • Esc: Stop playback and clear In/Out selection
  • T: Toggle time display between Bars & Beats / Seconds
  • Shift + T: Add new track
  • Ctrl + T: Trim silence on focused track
  • M: Toggle metronome click
  • L: Toggle loop on focused track
  • Ctrl+E: Export master WAV mixdown
